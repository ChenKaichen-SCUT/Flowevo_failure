# FlowEvo–ScienceWorld 适配与保真审计

本项目直接导入固定提交 `36e81efd4d1fdbabca7366200b15808ebef157fa` 的上游类。它是新的 ScienceWorld 适配实验，不是 FlowEvo 论文已有 ScienceWorld 成绩的复现。

|上游组件|实际复用|必要的环境适配|证据|
|---|---|---|---|
|`alfworld_/executor.py:AlfWorldExecutor.run`|原方法直接继承，负责 L1、L2、L3 组合与动态回退|覆盖 ALFWorld 特定的执行循环、零模型搜索和停滞启发式；每步通过 ActionGateway|`tests/test_boundaries.py` 验证方法身份；真实 JVM 回放见 `artifacts/real_replay_verification.json`|
|`alfworld_/compiler.py:AlfWorldCompiler.compile`|成功筛选及模板/引导双产物流程|两种产物均由真实 DeepSeek 从自主成功公开轨迹生成；不继承 ALFWorld 手写蓝图、实体默认值和规则后备|私有 compilation 记录及公开导出索引|
|`alfworld_/schemas.py`|技能模板数据结构、参数实例化、执行轨迹、引导序列化|benchmark 标识为 scienceworld；评分留在宿主记录|实际模板和逐步日志|
|`alfworld_/skill_library.py`|三层存储、检索、准入替换、效用统计、抑制与序列化均直接调用|各组各顺序独立副本；批内冻结，批末按预定顺序发布|每批 bank 输入/输出哈希、准入/拒绝/治理事件|
|`run_20task_validation.py` 原生治理调度|20% L2/L3 留出率、1337 RNG、20 任务审计间隔、原生 utility/contrastive 计数口径|按批快照判断是否可留出，独立 RNG 顺序重建；L1 保留|v2 修订及 native_holdout 日志|
|`runtime` 调用接口|保留明确的生成/编译阶段语义|替换网络层为单一 DeepSeek 中央请求协调器、事务账本及关闭自动重试|所有真实实验请求的 endpoint/model/usage 审计|

不是把 ALFWorld 的家务解题模板改名。ScienceWorld 中没有手写加热、电路、植物或任务答案工作流。上游动态生成器的模糊匹配和“首个合法动作”兜底被严格 JSON 解析替代；合法性不被视为任务正确性。上游根据重复动作提前退出的启发式没有照搬，因为 ScienceWorld 中等待、加热、生长可以需要重复动作。各组使用同一 100 次宿主决策限制，同时记录环境 moves。

直接执行仍是参数化模板逐步执行，模板不适用时回退到当前状态的技能引导或动态规划。当前公开合法动作接口用于确定直接技能适用性；不使用隐藏分数判断是否重试。来源轨迹编译出的模板必须实例化为原始真实动作的有序子序列，不能把编译器自行补写的“理想解法”冒充观察所得。

共享状态解析只提取当前 `look` 中明示的房间名、门和容器开闭描述。缺失状态为 unknown；不会把旧房间的同名对象当作新房间真值。所有主比较组都得到相同解析结构，约束执行器也只读这些公开字段。这里的人工工程贡献是文本语法解析，不是“应该打开门”之类行动策略。

`discovery-v1` 是保留的工程校准记录：16 个任务运行后发现动作响应截断及原生 holdout 调度未完整接通。它被明确标记为 SUPERSEDED，费用计入总成本，成绩不混入 v2。随后统一将动作输出上限升至 4096，限制 reason 的格式长度，恢复原生治理调度，并从空库用新 Run 重跑全部 60 个探索任务。

真实 JVM 工程回放使用自主成功 TRAIN 轨迹的已保存响应，覆盖动态、引导、直接与直接失败回退路径；关闭新规则的回放观察哈希一致。这是工程证据，不能当成自然跨任务复用。自然运行的检索、绑定、直接执行、引导、回退和抑制数量以 `results/episodes.csv` 与最终中文报告为准。

批次在线语义是环境适配的明确改变：不是逐任务即时在线；同批后完成的任务不能看到先完成任务的成功。保存所有批次库版本可审计恢复，不能在恢复时隐式继承另一个组或另一个顺序的 TEST 学习。
